Einstieg

  1. Exporte holen. Kontoauszug als CSV aus dem Online-Banking; dazu optional PayPal, Kreditkarte, Splitwise, Flatex (wo genau).
  2. Importieren. Alle Dateien auf einmal unter Import hochladen. Das Format wird erkannt, Doppeltes übersprungen.
  3. Durchgehen. Jede offene Zahlung einmal einer Kategorie zuordnen (Tasten 1–9). „Regel merken“ anhaken, dann passiert es beim nächsten Mal von selbst.
  4. Anschauen. Dashboard, Investitionen, Jahr, Laufende Kosten. Jede Zahl ist anklickbar und führt zu den Zahlungen dahinter.

Ohne eigene Daten: auf dem leeren Dashboard „Erst mit Beispieldaten ansehen“ – erfundene Buchungen, jederzeit entfernbar. Alles liegt in einer Datei neben dem Programm, nichts verlässt den Rechner.

Jeden Monat

  1. Neue Exporte ziehen (Zeitraum seit dem letzten Import, Überschneidung ist egal).
  2. Importieren. Das Ergebnis zeigt, was neu ist und was die App automatisch erledigt hat.
  3. Den Rest durchgehen – mit Regeln meist nur eine Handvoll Zahlungen.

Fehlt ein Export oder passt etwas nicht, steht ein Zähler an Import bzw. Splitwise in der Seitenleiste und ein Hinweis im Dashboard.

Was automatisch passiert

Nach jedem Import, in dieser Reihenfolge. Nichts davon ist endgültig – jede Zuordnung lässt sich ändern.

  • Doppeltes wird übersprungen; Buchungen vor dem Stichtag entfernt.
    • {% if 'paypal' in enabled %}
  • PayPal: die Kontoabbuchung wird mit der echten PayPal-Zahlung verrechnet – gezählt wird der Händler.
    • {% endif %} {% if 'card' in enabled %}
  • Kreditkarte: die Sammelabbuchung wird mit den Kartenposten verrechnet, die bis zum Abrechnungsstichtag genau dazu passen.
    • {% endif %}
  • Regeln setzen Kategorien; danach die eingebaute Automatik (Auslandszahlung → Urlaub, Splitwise-Stichwörter).
  • Fixkosten mit Anteil werden auf deinen Prozentsatz gekürzt.
    • {% if 'splitwise' in enabled %}
  • Splitwise: hat jemand anderes bezahlt, zählt dein Anteil. Hast du bezahlt, wird die Kontobuchung auf deinen Anteil gekürzt (centgenau, ±3 Tage, Karte ±7); sonst wird der Anteil mit Bargeld-Abhebungen oder als Gutschrift verrechnet. Ausgleichszahlungen zählen nicht.
    • {% endif %}
  • Rückzahlungs-Regeln verrechnen Eingänge, die du unter Laufende Kosten zugeordnet hast, mit der passenden Abbuchung.
  • Laufende Kosten werden aus regelmäßigen Zahlungen erkannt (monatlich oder quartalsweise, ab drei Zahlungen). Was du von Hand aufnimmst oder ausblendest, hat Vorrang.

Probleme

Format nicht erkanntIm Import-Ergebnis „Spalten zuordnen“: Datum, Betrag (oder Soll/Haben), Empfänger wählen – gilt danach für jede Datei mit dieser Kopfzeile (Einstellungen → Datenquellen zeigt die gemerkten Zuordnungen). PDF geht nicht, nur CSV oder XLSX.
Zahl stimmt nichtAuf die Zahl klicken – die Liste dahinter zeigt jede Buchung. Dort Kategorie, Aufteilung oder „zählt nicht“ ändern.
Etwas zählt doppeltMeist fehlt ein Export (PayPal, Karte) oder eine Verknüpfung. Die Hinweise im Dashboard sagen, was fehlt.
Abo falsch in Laufende Kosten✕ an der Zeile blendet es aus; „Vorschläge“ und die Suche dort nehmen Fehlendes auf; ✎ legt zwei Gruppen zusammen.
Alles zurückUnter Sicherung einen früheren Stand zurückspielen – vor jedem Zurückspielen wird der aktuelle Stand gesichert.
